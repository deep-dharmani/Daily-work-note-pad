# Daily Work Note Pad 📝

A simple Python project for writing and managing daily work notes.

## About the Project

Daily Work Note Pad is a beginner-friendly Python project that helps users keep track of their daily tasks and important notes.

This project was created to practise Python file handling and improve programming logic.

## Features

- Write and save daily work notes.
- Keep notes stored in a file.
- Read previously saved notes.
- Practise Python file handling.
- Simple and easy-to-understand code.

## Technologies Used

- Python
- File Handling

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/deep-dharmani/Daily-work-note-pad.git
   ```

2. Open the project folder:

   ```bash
   cd Daily-work-note-pad
   ```

3. Run the Python file:

   ```bash
   python main.py
   ```

   Replace `main.py` with your actual Python filename if it is different.
